Ты — senior frontend-разработчик. Создай тему для блога/сайта документации.

СТЕК:
- Чистый HTML + CSS + Vanilla JS (без фреймворков и сборщиков)
- Никаких внешних зависимостей, кроме подсветки кода

ЗАДАЧИ:

1. Тема дня/ночи:
   - Кнопка-тумблер в шапке (иконки ☀️/🌙, плавный переход)
   - Определение системной темы через prefers-color-scheme при первом заходе
   - Сохранение выбора в localStorage
   - Переключение через CSS-переменные в :root и [data-theme="dark"]
   - Без "мигания" при загрузке (inline-скрипт в <head>)

2. Оформление кода:
   - Подсветка через Prism.js или highlight.js (CDN)
   - Кнопка "копировать" на каждом блоке кода
   - Плавный горизонтальный скролл для длинных строк
   - Красивая тема подсветки, подходящая и для дня, и для ночи

3. Поиск по сайту:
   - Поле поиска в шапке
   - Живой поиск (инпут → мгновенные результаты)
   - Индекс формируется из заголовков h2/h3 и параграфов на странице
   - Подсветка совпадений, переход к найденному блоку по клику
   - Debounce 200мс, регистронезависимый

4. Адаптивность:
   - Mobile-first, breakpoints 640px / 1024px
   - Тумблер и поиск на мобильных не ломают верстку

ДИЗАЙН:
- Минимализм, читаемость, максимум воздуха
- Светлая тема: тёплый фон (#fafafa), тёмный текст (#1a1a1a)
- Тёмная тема: фон #121212, текст #e8e8e8, акценты мягкие
- Шрифт: системный стек (-apple-system, Segoe UI, sans-serif)
- Скругления 8–12px, аккуратные тени
- Переходы тем 0.25s ease

ОГРАНИЧЕНИЯ:
- Общий CSS ≤ 300 строк, JS ≤ 150 строк
- Никаких jQuery, Bootstrap, Tailwind
- Доступность: aria-label на тумблере, focus-visible стили

ВЫВОД:
Один HTML-файл с инлайн CSS и JS + краткое пояснение ключевых мест.
