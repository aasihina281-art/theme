СТЕК
═══════════════════════════════════════════
- Чистый HTML + CSS + Vanilla JS (ES2020+)
- Никаких фреймворков, сборщиков, препроцессоров
- Внешние зависимости: ТОЛЬКО один CDN-скрипт подсветки кода

- Всё остальное — инлайн в одном файле

═══════════════════════════════════════════
1. ТЕМА ДНЯ / НОЧИ
═══════════════════════════════════════════
- Тумблер в шапке с иконками ☀️/🌙, плавный переход 0.25s ease
- Приоритет источника темы:
    1) localStorage["theme"] (если задан)
    2) prefers-color-scheme (системная)
    3) fallback: светлая
- Сохранение выбора в localStorage
- Реализация через CSS-переменные:
    :root { --bg: ...; --fg: ...; ... }
    [data-theme="dark"] { --bg: ...; --fg: ...; }
  Атрибут data-theme ставится на <html>
- БЕЗ FOUC: inline-скрипт в <head> ДО подключения CSS,
  который читает localStorage/prefers-color-scheme
  и сразу ставит data-theme
- Слушаем изменение prefers-color-scheme, но применяем его
  только если пользователь НЕ сделал явный выбор вручную

═══════════════════════════════════════════
2. ОФОРМЛЕНИЕ КОДА
═══════════════════════════════════════════
- Подсветка через выбранный CDN
- Тема подсветки ОБЯЗАНА переключаться вместе с сайтом
  через CSS-переменные (переопредели токены Prism/hljs
  внутри :root и [data-theme="dark"]),
  а НЕ через подключение двух разных CSS-файлов
- Кнопка "копировать" на каждом <pre><code>:
    • позиционирована в правом верхнем углу блока
    • при клике меняет текст на "✓ Скопировано" на 1.5s
    • использует navigator.clipboard с fallback на
      document.execCommand('copy') для http-окружений
    • aria-label="Скопировать код" + aria-live="polite"
      для озвучивания статуса
- Горизонтальный скролл: overflow-x: auto на <pre>,
  кастомный тонкий скроллбар, без переноса строк
- На тач-устройствах кнопка копирования всегда видима,
  на десктопе — появляется на hover блока

═══════════════════════════════════════════
3. ПОИСК ПО САЙТУ
═══════════════════════════════════════════
- Поле ввода в шапке (input type="search")
- Живой поиск: инпут → мгновенные результаты в выпадающей панели
- Индекс строится на клиенте из контентной части <main>:
    • заголовки h2, h3
    • параграфы <p>
  Каждому элементу присваивается id (если нет) для якорей
- Debounce 200мс, регистронезависимый (toLowerCase)
- Дедупликация: если заголовок и следующий за ним параграф
  совпали — показывать одним пунктом (заголовок + сниппет)
- Лимит результатов: 10
- Сниппет: 60 символов до и после совпадения
- Подсветка совпадений безопасно: строим через
  createElement/createTextNode, НЕ через innerHTML
- Клавиатура:
    ↑ / ↓ — навигация
    Enter — переход к активному результату
    Esc — очистка и закрытие
- Клик/Enter → scrollIntoView({behavior, block:'start'})
- На целевых заголовках: scroll-margin-top: 80px
  (компенсация фиксированной шапки)
- Если результатов нет — показать "Ничего не найдено"
- Клик вне панели закрывает её
- aria-live="polite" на контейнере результатов
- При пустом инпуте панель скрыта

═══════════════════════════════════════════
4. АДАПТИВНОСТЬ
═══════════════════════════════════════════
- Mobile-first
- Брейкпоинты: 640px и 1024px
- На мобильных (<640px):
    • поиск и тумблер не ломают верстку шапки
    • допустимо свернуть поле поиска в иконку,
      раскрывающуюся по тапу (реши сам, что чище)
    • панель результатов занимает доступную ширину
- Никаких горизонтальных скроллов страницы

═══════════════════════════════════════════
5. ДОСТУПНОСТЬ
═══════════════════════════════════════════
- Тумблер: role="switch", aria-checked, aria-label
  с текущим состоянием ("Тёмная тема включена/выключена")
- Кнопка копирования: aria-label + aria-live статуса
- Поиск: aria-live="polite" на результатах
- :focus-visible стили для всех интерактивных элементов
  (заметная обводка, не через outline: none без замены)
- prefers-reduced-motion: reduce — отключить
  переходы темы и scroll-behavior: smooth
- Семантические теги: header, main, nav, article
- Контраст текста в обеих темах ≥ WCAG AA (4.5:1)

6. ДИЗАЙН
═══════════════════════════════════════════
- Минимализм, читаемость, много воздуха
- Светлая тема:  фон #fafafa, текст #1a1a1a,
                 акцент — приглушённый синий/индиго
- Тёмная тема:   фон #121212, текст #e8e8e8,
                 акцент — мягкий, не неон
- Шрифт: -apple-system, BlinkMacSystemFont, "Segoe UI",
         Roboto, sans-serif
- Моно-шрифт: ui-monospace, SFMono-Regular, Menlo, monospace
- Скругления 8–12px, аккуратные мягкие тени
- Максимальная ширина контента ~720px, центрирование
- Типографика: line-height 1.6–1.7 для параграфов,
  осмысленная шкала заголовков

7. ДЕМО-КОНТЕНТ (обязательно)
═══════════════════════════════════════════
Страница должна демонстрировать все фичи:
- Минимум 4 секции с заголовками h2
- Минимум 2 подзаголовка h3
- Минимум 3 блока кода:
    • короткий (JS)
    • с длинной строкой (для проверки скролла)
    • с символами, требующими экранирования (< > &)
- Текстовые абзацы, по которым будет работать поиск
- Одна секция с якорем, к которому явно ведёт поиск
