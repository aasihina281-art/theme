DocsTheme

    DocsTheme

    Минималистичная тема для блога и сайтов документации: день/ночь, живой поиск, подсветка кода. Один файл, ноль зависимостей кроме Prism.js.

    Тема дня и ночи

    Переключение темы построено на CSS-переменных: значения объявлены в :root для светлой темы и переопределены в [data-theme="dark"]. Атрибут ставится на <html>, поэтому перекрашивается вся страница разом, с плавным переходом 0.25s ease.

    Определение системной темы

    При первом заходе (когда в localStorage ничего нет) мы спрашиваем операционную систему через prefers-color-scheme:

    const saved = localStorage.getItem('theme');
const theme = saved
  ?? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');

document.documentElement.dataset.theme = theme;

    Без «мигания» при загрузке

    Ключевой приём — маленький inline-скрипт прямо в <head>, до стилей и контента. Тема применяется до первой отрисовки, поэтому пользователь не видит вспышку белого фона.

    Сохранение выбора

    Клик по тумблеру меняет атрибут и пишет выбор в localStorage. Дальнейшие визиты всегда начинаются с выбранной темы:

    button.addEventListener('click', () => {
  const next = document.documentElement.dataset.theme === 'dark' ? 'light' : 'dark';
  document.documentElement.dataset.theme = next;
  localStorage.setItem('theme', next);
});

    Оформление кода

    Подсветка сделана на Prism.js с CDN — это единственная внешняя зависимость темы. Для блоков используется тема Tomorrow: она одинаково хорошо читается и на светлом, и на тёмном фоне страницы, потому что сам блок кода всегда остаётся «карточкой» на тёмном подложке.

    Кнопка «копировать»

    Каждый блок <pre> оборачивается в карточку с шапкой: метка языка слева, кнопка копирования справа. Используется современный Clipboard API с graceful-фоллбэком:

    async function copyCode(pre) {
  try {
    await navigator.clipboard.writeText(pre.innerText);
    return true;
  } catch {
    const ta = document.createElement('textarea');
    ta.value = pre.innerText;
    document.body.appendChild(ta);
    ta.select();
    document.execCommand('copy');
    ta.remove();
    return true;
  }
}

    Горизонтальный скролл длинных строк

    Длинные строки не ломают вёрстку: overflow-x: auto плюс тонкий аккуратный скроллбар, а scroll-behavior: smooth делает прокрутку приятной:

    .code-block pre {
  overflow-x: auto;          /* плавный горизонтальный скролл */
  scrollbar-width: thin;     /* Firefox */
}
.code-block pre::-webkit-scrollbar { height: 8px; }
.code-block pre::-webkit-scrollbar-thumb {
  background: rgba(255, 255, 255, .2);
  border-radius: 4px;
}

    Живой поиск

    Поле поиска в шапке даёт мгновенные результаты без бэкенда. Индекс строится один раз при загрузке из всех заголовков h2/h3 и параграфов внутри секций. Поиск регистронезависимый, с debounce 200 мс, чтобы не перерисовывать список на каждую клавишу.

    Индексация страниц

    const index = [];
document.querySelectorAll('#content section').forEach(sec => {
  sec.querySelectorAll('h2, h3').forEach(h => {
    index.push({ id: sec.id, title: h.textContent, text: '', kind: h.tagName });
  });
  sec.querySelectorAll('p').forEach(p => {
    index.push({ id: sec.id, title: p.textContent.slice(0, 60), text: p.textContent, kind: 'P' });
  });
});

    Debounce и подсветка совпадений

    В выводе результатов найденный фрагмент оборачивается в <mark>. Клик по результату прокручивает к секции, подсвечивает её пульсацией и выделяет точное вхождение текста:

    function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
input.addEventListener('input', debounce(runSearch, 200));

    Переход к найденному блоку

    Для плавной прокрутки у секций задан scroll-margin-top, чтобы липкая шапка не закрывала заголовок цели. Навигация работает и с клавиатуры: стрелки вверх/вниз по списку результатов, Enter — открыть, Escape — закрыть.

    Адаптивность

    Стиль — mobile-first: базовые стили рассчитаны на узкие экраны, затем два media-запроса расширяют сетку. На мобильных поле поиска переносится на вторую строку шапки (порядок задаёт order во flex-контейнере), тумблер и логотип остаются в первой. Начиная с 640px поиск встаёт в одну линию, а с 1024px контент раскрывается на полную ширину колонки чтения.

    @media (min-width: 640px) {
  .search-wrap { order: 0; width: auto; flex: 1 1 200px; }
}
@media (min-width: 1024px) {
  main { max-width: 820px; padding-top: 3.5rem; }
}

    Доступность

    Тумблер имеет aria-label, поле поиска подписано, список результатов — роль listbox. Все интерактивные элементы имеют стили :focus-visible с заметным кольцом обводки, видимое и в светлой, и в тёмной теме.
